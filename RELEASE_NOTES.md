# LeadThink Git Tool v1.2.4

## What this release includes

- One-button club setup from a GitHub profile or organization URL.
- Creates or reuses the public `LeadThinkInnovation4HClub` repo for a member.
- Clones the repo into the selected local workspace.
- Creates the standard club folder structure.
- Adds starter README files and `.gitignore`.
- Shows clear setup progress and completion feedback.
- Shows whether the GitHub repo or local clone already existed.
- Adds student-friendly Git Operations explanations.
- Adds feedback after Commit, Pull, Push, Fetch, Branch, Merge, and project-folder actions.
- Remembers the last selected local repo so Git Operations work after reopening the app.
- Shows the GitHub CLI login command: `gh auth login -w`.

## Installer

Download `LeadThink Git Tool Setup 1.2.4.exe` from this release.
