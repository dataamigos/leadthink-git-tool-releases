# LeadThink Git Tool Releases

Public download page for LeadThink Innovation 4-H Club members.

## Latest installer

Download the latest Windows installer from the GitHub Releases page:

https://github.com/dataamigos/leadthink-git-tool-releases/releases/latest

## First-time GitHub login

If GitHub authentication is not complete on a student computer, run this once:

```powershell
gh auth login -w
```

Then follow the browser sign-in steps.

## Source code

The application source code is private. Club members should use the installer from Releases.
